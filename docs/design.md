# 实现设计与科学边界

## 问题与比较

目标是检验增强子链接能否改善 MARADONER 的 motif 活性扰动识别。候选网络是序列、区域和链接支持的假设集合。TF 扰动是性能验证核心，但不进入 ATAC 建网或选择权重；没有合适扰动数据时只能完成建网，不能作改善结论。

当前数据候选包括后部类器官（WTC/Qian/day30）、HSPC、A375、CAT-ATAC 子集。必须从原始对象确认细胞背景、条件、时间、供体/真实批次、NTC、单 TF、原始 RNA counts 和可用 fragments。细胞系批次不能伪装为不同人体供体；使用真实独立培养批次作为实验单位并记录语义。条件不匹配者只能列为迁移探索。现有候选未完成对象层审核，不自动指定生产数据。

## 固定特征

基因组、注释和 motif 版本需预先冻结。代表 TSS 采用每基因 transcript_id 字典序最小的转录本，与表达无关；这是一项可复现工程约定，不保证最活跃转录本。TSS 为 0-based，启动子为 [TSS−2000,TSS+2001)，左端截到 0。所有启动子的并集从增强子中扣除；拆分片段继承原峰链接权重，位点按片段只计一次。扫描器对两类区域使用同一 MEME 资源、背景和阈值。位点数构成 motif 矩阵，不把扫描分数直接当占据概率。

原始 P 为基因×motif 启动子位点数，H 为链接权重×增强子位点数之和。以 P 的每列 RMS 共同缩放所有矩阵，再对每个链接臂计算 α=||P||F/||H||F；比较 P、P+αH、P+0.5αH 和 P+2αH。零 H 退化为 P。所有臂共用非恒定列集合；每个预定 TF 删除后仍需非恒定。上游 loading transformation 明确为 none，不追加分位数/秩转换。

距离臂在冻结的 cis 窗口中用逆距离权重。置换按每个基因及距离层从候选区抽取不同区域，保留该层链接数量与权重多重集；可抽中原区域，不强制无固定点。当前实现不额外保持增强子全局度数或 GC 分布，因此应把它解释为这一特定零假设。主结果以固定 α=1 倍配置为准；敏感性和种子不能当额外生物样本。

## 活性和验证

RNA 在真实 donor×batch×condition×cell_type×role×target 上求和，随后 log1p(CPM)。不把 guide 或细胞当独立生物重复，不插补 RNA/ATAC 配对。每目标使用 KO 和匹配 NTC；所有臂删除同一目标基因表达行。归一化分母在删除前冻结，因此这是条件于原始库归一化的分析。

真实 MARADONER 使用固定源码提交；直接调用 create_project API 是为了避免上游 CLI n_jobs 浮点类型问题，fit/predict 仍运行真实实现。软件输入/输出轴必须完整一致，禁止静默滤 motif 或失败后切换 ridge。样本 activity 来自真实 U_raw 与组均值；上游仅有组级不确定性时，样本 SD 留空。组 Z 是模型条件性辅助统计，不是供体重复的因果证据。

每单位 KO−NTC 的绝对活性差异，家族内取最大；家族并列采用平均秩。TF 归属多个家族时，取可接受家族的最好秩，并记录歧义数；零假设用相同可接受家族数校准。最大值对大 motif 家族的偏倚不能消失，因此同时输出平均 motif 百分位秩敏感性。按家族、供体和条件逐层等权，家族×供体交叉重采样报告相对启动子 MRR 差异；少数供体/家族下区间仅描述。

NTC–NTC 活性差异评估噪声幅度；随机伪目标排名评估 MRR 零假设，二者不能相互替代。只有单一 NTC pseudobulk 时输出不足，不拆成虚假生物重复。多个条件分别运行，汇总时条件等权，不能按细胞数加权。

## 留出与稳健性

所固定上游版本的内部 gof 拟合使用全基因，故主流程禁用严格留出 FOV。相同 p×m 或相同泄漏不意味着有效复杂度相等，也不抵消偏倚。独立 `me holdout` 仅以训练基因拟合，再由测试 B 与训练活性预测；测试表达仅进入最终行中心化评分。结果是条件于冻结归一化的跨样本表达变异 FOV，不是未见绝对表达预测。该辅助接口已测测试表达修改不会改变训练/预测；尚未作真实数据科学评估。

供体留一必须从 ATAC fragments 重建 scE2G，不能仅从最终边表删供体。`fragments --heldout-donor` 支持排除，links receipt 绑定实际建网成员。每折生成独立 fragments、链接、samples、配置与输出，再运行 `scripts/run_robustness.py` 检查与汇总。该脚本不冒充已完成缺失的 scE2G 重建；折结果只作为稳健性重复，不扩大生物学 n。
